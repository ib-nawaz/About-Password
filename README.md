# 🔐 Random Password Generator

A simple **Random Password Generator** built using **HTML, CSS, and JavaScript**.

### ✨ Features

* 🎲 Generate random passwords
* 💪 Password strength indicator
* 👁️ Show / Hide password functionality
* 🔢 Supports uppercase, lowercase, numbers, and special characters
* ⚡ Simple and user-friendly interface

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

### 📌 About the Project

This project generates random passwords and checks the strength of a password while the user types. It also includes a **Show / Hide Password** feature for easily viewing or hiding the entered password.

The project helped me practice **JavaScript DOM manipulation, event handling, input validation, and password generation**.
